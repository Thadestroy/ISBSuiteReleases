Requirements

  • Windows 10 or later
  • Twitch account (optional to open the app; you want it connected for chat and events)
  • OBS, Streamlabs, or any tool with a Window Capture source

Install steps

  1. Download

    Get ISBSuiteSetup_X.X.X.exe from the latest release above (or GitHub releases). Do not use third-party mirrors.

  2. Run the installer

    Windows SmartScreen may warn on first run while the installer is not Authenticode-signed. Choose More info, then Run anyway. Prefer checking the release asset name and size on GitHub before you run it.

  3. Finish setup

    Complete the wizard and launch ISB Suite.

  4. Connect Twitch

    Open Integrations and sign in with device code OAuth for chat and EventSub.

Only download from Thadestroy/ISBSuiteReleases. After install, the app checks for updates on launch.

Capture setup (Window Capture)

ISB Suite draws your overlay in its own transparent window. Nothing shows on broadcast until your streaming software captures that window.

  1. Add a Window Capture source in OBS or Streamlabs.
  2. Select ISBSuite.exe: ISB Suite - Capture. Prefer Capture Method Windows 10 and Window Match Priority Window title must match.
  3. In the app, use Overlay Layout to place widgets on the stage.

Winner text centers on the wheel. The spin pointer sits on the right side of the wheel.
