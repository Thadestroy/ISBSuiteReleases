Chat commands

Built in commands plus notes on permissions, aliases, Match anywhere, and Advanced Settings limits. Custom commands you create live in Automations and Chat Bot.

Viewer commands

CommandDescription
!joinJoin the current wheel when a session is active
!pointsCheck viewer points balance (or your custom command name)
!givepoints @user amountGive your own points to another viewer
!gamble amountWager points on a configurable win chance roll (decimals and percents ok, e.g. 50.2 or 34.7%; rounds to a whole stake)
!giveawayEnter an active giveaway
any shop commandSpend points on shop items you configured

Permission levels

Custom commands and editors that expose permission use these levels:

  • Everyone: any viewer
  • Subscribers: subs, VIPs, mods, broadcaster
  • VIPs: VIPs, mods, broadcaster
  • Moderators: mods and broadcaster only
  • Broadcaster: broadcaster only

Aliases and Match anywhere

Aliases: Automations, Chat Bot commands, Chat Games join commands, Viewer Points commands, shop items, point drop claims, and Community Goal check commands can define alternate names. The longest matching alias wins. Leftover text after a longer alias becomes {input}.

Match anywhere in message (optional, under Advanced Settings): match as a whole word anywhere in chat, not only at the start. Useful for /me !command and mid-chat triggers. Space boundary rules still apply (!spin will not match inside !spinwheel). Off by default.

Advanced Settings limits

Viewer Points commands (including shop redeem and point-drop claim), Chat Game join, Community Goal check commands, Automations / Chat Bot custom commands, and related editors share one Advanced Settings block:

  • Permission - who may run the command
  • Time cooldown - None, Global, or Per User
  • Per stream limits - max fires globally and/or per user (0 = unlimited); reset when a new stream session starts
  • Optional chat replies - separate messages for on cooldown vs hit limit ({time} is available on cooldown replies)
  • Aliases and Match anywhere - as above

New limit fields default to unlimited; existing cooldowns keep working. Channel Point redemptions are different: Twitch still accepts the redeem and charges points; ISB Suite only skips running the automation when blocked (reject / refund is not supported yet).
