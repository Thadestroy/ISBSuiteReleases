Chat commands

Built in commands plus notes on permissions, aliases, Match anywhere, and Advanced Settings limits. Custom commands you create live in Automations and Chat Bot.

Permission levels

Custom commands and editors that expose permission use these levels:

  • Everyone: any viewer
  • Followers: followers, subs, VIPs, mods, broadcaster
  • Subscribers: subs, VIPs, mods, broadcaster
  • VIPs: VIPs, mods, broadcaster
  • Moderators: mods and broadcaster only
  • Broadcaster: broadcaster only
  • Specific User(s): only the named viewers (no mod or broadcaster bypass)

On Chat Bot custom commands and Chat Games start commands, a role can also include named users who do not meet that role (for example Moderators plus a regular viewer). Specific User(s) stays locked to the list only. YouTube maps Subscribe to Followers, Member to Subscribers, and VIP+ to Moderators. Specific User lists accept a YouTube @handle. Full ladder: YouTube.

Aliases and Match anywhere

Command names: type the trigger the way viewers will send it in chat, including a leading ! (for example !spin). Empty command-name and alias fields show a muted !command / !alias hint. Other prefixes such as ?help still work. The app does not auto-add !.

Aliases: Automations, Chat Bot commands, Chat Games join commands, Viewer Points commands, shop items, point drop claims, Community Goal check and contribute commands, and Saved List Read/Add commands can define alternate names. The longest matching alias wins. Leftover text after a longer alias becomes {input}.

Match anywhere in message (optional): match as a whole word anywhere in chat, not only at the start. On Chat Bot custom commands this is on the Add/Edit card; on Viewer Points, Community Goals, Saved Lists, Chat Games, and Automations it is under Advanced Settings. Useful for /me !command and mid-chat triggers. Space boundary rules still apply (!spin will not match inside !spinwheel). Off by default.

Don't trigger from the broadcaster or linked bot (optional; Chat Bot, Alerts, Automations Chat Command, Chat Games start, and Saved Lists): the command will not fire from your Twitch account or a linked bot account, whether it is at the start or mid-message. Same rule either way you send chat. Off by default.

Allow checking another viewer (optional): treat the first leftover word as a viewer (@user / username). {user} becomes that person and leftover text is {input}. On by default for Viewer Points balance, Follow Age, and Watch Time. Off by default on Automations Chat Command and Chat Bot custom commands so !love pizza keeps pizza as {input}. Cooldown and permission still apply to whoever typed the command. Use {caller} for the typer when {user} is a looked-up subject.

Advanced Settings limits

Viewer Points commands (including shop redeem and point-drop claim), Chat Game join, Community Goal check and contribute commands, Saved List Read/Add, Automations, and related editors share one Advanced Settings block. Chat Bot custom commands keep aliases, Match anywhere, Don't trigger, and Allow checking another viewer on the Add/Edit card; Cooldown & Limits stay under Show Advanced.

  • Permission - who may run the command
  • Time cooldown - None, Global, or Per User. Optional burst: if used N times within a window you set, a longer cooldown starts. The normal per-use duration is independent and can be off.
  • Per stream limits - max fires globally and/or per user (0 = unlimited); reset when a new stream session starts
  • Optional chat replies - separate messages for on cooldown vs hit limit ({time} is available on cooldown replies)
  • Aliases and Match anywhere - as above

New limit fields default to unlimited; existing cooldowns keep working. Channel Point redemptions are different: Twitch still accepts the redeem and charges points; ISB Suite only skips running the automation when blocked (reject / refund is not supported yet).

Community Goal contribute Advanced Settings also has optional point-amount caps (max points per stream, and max per user per stream). Those are separate from max fires. 0 = unlimited. They reset on a new stream and when you Refund VP.
