Extra tips

Hands-free streaming

  • Set up chat commands for everything you would normally click.
  • Let mods control the wheel via !startwheelspin, !join, !spinwheel, and related commands.
  • Use channel point redemptions for viewer-driven spins.
  • Use Viewer Points shop redeemables for viewer-controlled sounds and wheels.

Cascading wheels

  1. Create multiple wheel presets (for example Category Picker and Game Picker).
  2. On an entry in Category Picker, add Trigger Automation.
  3. That automation loads the Game Picker wheel (optionally auto spins).
  4. Result: winning Survival Games can load a wheel full of survival games.

Walk-on sounds

  1. Automation: First Message Per Stream. Blank username greets everyone once; named username is a special walk-on.
  2. Blank and named walk-ons can both fire for the same person.
  3. Enable Only When Live to skip setup / starting soon screens.
  4. Attach a sound with volume adjusted to taste.

Stream Deck

  1. Create a custom command automation (for example !quickspin) set to Broadcaster Only.
  2. In Stream Deck, use the Twitch Chat action and send that command.
  3. One button can load and spin any preset instantly.

Multi-trigger automations

A single automation can respond to multiple triggers. For example, play the same hype sound on any of: a Tier 2 sub, a 100-bit cheer, or a 5-viewer raid. Add as many triggers as you need on one rule instead of maintaining separate rules. See Automations.

Chained automations

  1. Create automation A (for example a chat command) that runs sound or chat actions, then Run Chat Bot or Automation targeting automation B.
  2. Automation B can itself run another rule. Every hop still has {user} and the rest of the original chatter variables.
  3. Use this for multi-step flows (announce, then timer, then wheel) without re-entering the same user context.
  4. Loops are detected automatically; keep intentional chains under the 20-hop limit.

Discord from automations

  1. Add named webhooks under Integrations, Discord Webhooks, and Test each one.
  2. On an automation, enable the Discord Webhook action and select one or more webhooks.
  3. Reuse your Send Chat Message text, write a Discord-only message, or both. Variables resolve before send.
