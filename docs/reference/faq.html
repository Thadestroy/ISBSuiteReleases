FAQ and troubleshooting

Common fixes. For bugs and feature requests, open an issue.

Cursor disappears in a fullscreen game

Symptom: You play in fullscreen with OBS running. Your mouse cursor vanishes on your monitor, but may still appear in the OBS preview. This often happens with Game Capture for the game plus Window Capture (Windows 10 / WGC) for ISB Suite Capture stacked on top.

This is not an ISB Suite bug. It is a known interaction between Windows Graphics Capture (WGC) and certain fullscreen games. WGC forces a software cursor; in exclusive fullscreen the game takes over the display and Windows often cannot draw that cursor on your monitor. Windowed and borderless modes usually work.

Minecraft Java is a common example. Many streamers fix it by switching Minecraft to the Vulkan renderer, or by turning Exclusive Fullscreen off. Other games can hit the same issue depending on engine and fullscreen mode.

  1. Minecraft: switch to Vulkan, or turn Exclusive Fullscreen off if available.
  2. Any game: ensure "Disable fullscreen optimizations" is unchecked on the game exe (Properties, Compatibility).

Twitch not connected

  1. Go to Integrations.
  2. Click Connect Twitch and follow device code login.
  3. Grant permissions for chat and EventSub.

Chat commands not working

  • Verify Twitch connection on Integrations.
  • Commands are case insensitive but must match exactly (!spinwheel not !spin wheel).
  • Check the user has the required permission level.
  • If you use Match anywhere, remember space-boundary rules still apply.
  • Confirm Advanced Settings cooldown / per stream limits are not blocking the fire.

Channel points not triggering

  • Confirm EventSub shows connected on Integrations.
  • Reward title in the automation must match the Twitch reward title exactly.
  • Redeem once while connected so the reward ID auto populates.

Audio not playing

  • Sounds are copied into app data when you save. If an older setup points at a missing file, re pick the sound once.
  • Check volume is not 0.
  • Supported formats: .mp3, .wav, .mp4, .m4a, .wma
  • Check the Sound Queue is not paused.
  • Confirm the Play Sound / TTS action uses the right bus under Settings > Audio Output Channels.

Backups and restore

  • Everything lives under Settings > Backups: schedule, create, restore, export, and import.
  • A backup is a standard .zip of your recoverable data (config, state, database, media). Create and export write that same pack; restore and import apply it (full replace + app restart).
  • Choose how often to create backups and how many to keep. Secrets (tokens, keys, license) are included by default - turn that off before sharing a file.
  • After importing on a new PC, re-check Settings > Audio Output Channels - device IDs may not match.
  • ISB Suite also keeps lightweight safety copies whenever you save so a single corrupt file can recover without a full restore. You do not manage those separately.

Overlay or widgets not showing on stream

  • Add a Window Capture of the ISB Suite Capture window. See Download.
  • Confirm the widget is on the active layout and visible.
  • Check it is not cropped out of your capture.

Alerts not showing

  • Place an Alert Box widget on the active layout.
  • Verify the alert rule is enabled.
  • Check trigger thresholds (for example minimum bits).
  • If several alerts match, only the most specific one fires.

Point drops not spawning

  • Place a Point Drop widget on the active layout.
  • Check interval, spawn chance, and only when live settings.
  • The spawn interval check runs on a timer - wait for the configured interval to elapse.

Edited point drop still uses old claim message or amount

  • While a drop is active, claim amount, claim slots, claim command, and chat templates stay frozen from when that drop spawned.
  • Saving the Point Drop editor updates the stored config for the next spawn only.
  • {amount} in spawn/claim messages reflects the active spawn's points per claim, not a later edit.

Tiltify not triggering

  • Verify the Tiltify integration shows as connected on Integrations.
  • If the session token expired, the app shows a reconnect window - re-authenticate.
  • Donation polling runs on a short interval, so there may be a brief delay.
  • Confirm any automation or alert that listens for Tiltify donations is enabled and thresholds match.

Discord webhook not sending

  • Save named webhooks under Integrations, Discord Webhooks.
  • Use Test on Integrations before relying on automations.
  • Confirm the automation includes the Discord Webhook action with the intended webhooks selected.
  • Webhook URLs should start with https://discord.com/api/webhooks/ (legacy discordapp.com URLs also work).

Updates

ISB Suite checks for updates on launch and can download and install with a single click when a new version is available.
