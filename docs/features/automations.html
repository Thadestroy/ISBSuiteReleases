Automations

Connect Twitch events and custom commands to actions: wheels, sounds, chat, Discord, counters, giveaways, alerts, TTS, timers, randomized sets, and chains into Chat Bot or other automations.

Overview

Automations live in the Automations tab. Overview pages support instant name search and optional custom groups (named groups, chip filters; ungrouped items list first).

Chat Bot vs Automations: both tabs share the same trigger and action building blocks. Prefer Automations when the rule is driven by Twitch events (channel points, bits, raids, follows, and so on) or needs a long action chain. Prefer Chat Bot when the rule is mainly a custom !command or timed chat message. Either tab can call the other with Run Chat Bot or Automation.

Cooldown and limits

Every automation can combine a time cooldown (None / Global / Per User) with per stream limits (max fires globally and/or per user; 0 = unlimited). Limits reset when a new stream session starts (same boundary as walk-ons). Separate optional chat replies for on cooldown vs hit limit.

Channel Point redemptions: Twitch still accepts the redeem and charges points. ISB Suite only skips running the automation when blocked. Reject or refund is not supported yet.

Chat command options

Custom Chat Command triggers support the same Advanced Settings pattern used across the app:

  • Permission: Everyone, Subscribers, VIPs, Moderators, or Broadcaster.
  • Aliases: alternate names that fire the same rule. Longer matching aliases win; leftover text becomes {input}.
  • Match anywhere in message: command can appear mid chat (for example /me !discord). Space-boundary rules still apply (!spin will not match inside !spinwheel). Off by default.
  • Cooldown and per stream limits: with optional chat replies.

Also see Chat commands.

Advanced patterns

  • Walk-on sounds: First Message Per Stream. Blank username greets everyone once; named username is a special walk-on. Blank and named can both fire. Enable Only When Live to skip setup screens.
  • Stream Deck: create a broadcaster-only custom command, then send that chat line from a Stream Deck Twitch Chat button.
  • Discord: add named webhooks on Integrations, then use the Discord Webhook action (one rule can post to multiple webhooks).
  • Chains: Run Chat Bot or Automation keeps original chatter context across hops (max 20; loops are blocked). Alerts use Run Alert.
  • Cascading wheels: entry action or Run Chat Bot or Automation loads a second wheel. See Wheel - Cascading and Use cases.
