Same engine as Automations

Chat Bot is not a separate runtime. Rules you create here use the same triggers, actions, cooldowns, aliases, Match anywhere, Randomized Action, Timer, Live Timer, Run Alert, and Run Chat Bot or Automation chaining as the Automations tab. Overview pages support name search and custom groups like other list pages.

Chat Bot response text routes to Twitch. Discord posts use the Discord Webhook action on Integrations.

When to use which

PreferWhen
Chat BotCustom !commands and timed or scheduled chat lines are the main job; you want built-ins (join, spin, watch time, and similar) in one overview
AutomationsTwitch EventSub events (channel points, bits, raids, follows, and so on) drive the rule, or you are building a multi-action stream workflow
EitherYou need chains - call the other tab with Run Chat Bot or Automation (up to 20 hops; original chatter variables preserved)

There is no wrong tab for a simple command that also plays a sound. Use Chat Bot if you think of it as a chat command; use Automations if you think of it as an event rule.

Command options

Custom commands support the full Advanced Settings block:

  • Permission levels: Everyone; Subscribers (subs, VIPs, mods, broadcaster); VIPs (VIPs, mods, broadcaster); Moderators (mods and broadcaster); Broadcaster only.
  • Aliases: alternate names that fire the same command. Viewers can type any alias; the longest matching alias wins when several could match. Leftover text after the match becomes {input}.
  • Match anywhere in message: optional whole-word match mid chat (for example /me !discord), not only at the start. Longest matching command still wins. Space-boundary rules apply (!spin will not match inside !spinwheel). Off by default.
  • Cooldown: None, Global, or Per User, with optional on-cooldown chat reply.
  • Per stream limits: max fires globally and/or per user (0 = unlimited), with optional hit-limit chat reply. Limits reset when a new stream session starts.

Community Goal check commands, Viewer Points commands, and Chat Game start/join commands also appear on the Chat Bot overview where applicable. Each row has the same enable/disable light as other Chat Bot cards (shared with that game, currency, shop item, drop, or goal). Edit opens that feature's settings. Arg-only built-ins such as !addgoal, !removegoal, and !endtimer stay out of the Run Chat Bot or Automation picker.

Timed and event messages

  • Post scheduled or interval-driven messages with variable substitution.
  • Attach the same event triggers available in Automations when a chat line should also react to stream events.
  • Use variables such as {user}, {time}, {top5Counter:CounterName}, and goal tokens. Full list: Message variables.

Live Timer Commands

The Chat Bot overview has a Live Timer Commands section for !pausetimer, !resumetimer, !addtime, and !removetime. !endtimer stays under Built-in Commands (ends a Live Clock or skips a delay Timer). See Live Timer and Chat commands.

Actions from Chat Bot

Beyond Send Message, a Chat Bot rule uses the same shared Actions editor as Automations (wheel, sound, Discord, counters, giveaway, Run Alert, TTS, Timer, Live Timer, Randomized Action, Run Chat Bot or Automation, Push Community Goal, and more). Open the Actions hub for per-action setup pages.
