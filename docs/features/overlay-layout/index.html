Overlay Layout

Design what gets captured by your streaming software using a drag-and-drop stage editor. Open a widget page for placement, properties, and how that widget pairs with Actions and other features.

At a glance

  • Nothing appears on stream until you add a Window Capture of ISB Suite - Capture. See Download.
  • Default stage 1920x1080 (custom sizes supported).
  • Widgets: Wheel, Alert Box, Point Drop, Static Image, Browser Source, Random Image Picker, Timer Widget.
  • Free: 2 overlay layouts. Full limits on Free and Pro.

Layout management

  • Create multiple named layouts (for example Main Scene, Wheel Scene, Just Chatting).
  • Switch from the list or assign a global hotkey per layout.
  • All widgets in the active layout render on the capture stage.
  • Duplicate a layout when you want the same widgets with different sizes or visibility for another scene.

Stage controls

  • Click to select; resize handles on all 8 sides; drag to reposition.
  • Set visibility per widget, or assign a hotkey to toggle during stream.
  • Preview Widgets / In Capture Window shows live renders.
  • Alt+drag to crop. Arrows nudge (Shift = 10px). Del removes. Esc deselects. Ctrl+Z/Y undo/redo.
  • Edges snap to the border - hold Shift to disable snap while dragging.

Shared widget properties

Every selected widget exposes the same transform and stage controls in the right panel:

  • X / Y / W / H (%) - position and size relative to the stage.
  • Visible - hide without deleting; pair with a widget hotkey for mid-stream toggles.
  • Crop - Left / Top / Right / Bottom percentages (Alt+drag on the canvas, or type values).
  • Layer order - Bring Forward / Send Backward when widgets overlap.
  • Widget hotkey - toggle that widget's visibility.

Widget-specific options (URL, preset, image path, picker binding) appear below those shared controls.

Layout transitions

Configure animated transition effects when switching between layouts so scene changes feel intentional on the capture stage. Keep heavy Browser Source widgets off layouts you flip often if CPU is tight.
