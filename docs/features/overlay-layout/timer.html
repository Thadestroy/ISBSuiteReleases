Timer Widget

Place a named Timer Widget on your overlay for delay-queue countdowns or a Live Clock (Subathon). Style the digits here; Automations drive the clock with Timer or Live Timer.

At a glance

  • Delay Timer: link the same preset on the Timer action.
  • Live Clock: drive with Live Timer (or Add Subathon).
  • Style font, weight, color, alignment, and shadow like Alerts text.

How it works

A Timer Widget shows the active countdown for a named preset on your capture stage. The same widget type covers two jobs:

  • Delay Timer - a rule's Timer action waits, then runs deferred actions. The widget shows that wait.
  • Live Clock - a subathon-style clock driven by Live Timer. Overlay Layout can Start / Pause / Resume / End; mods use chat commands to adjust time.

Setup

  1. In Overlay Layout, add a Timer Widget and create or select a named preset.
  2. Style font, weight, color, alignment, and drop shadow (same text style controls as Alerts). Text size still scales with the widget box height.
  3. For delays: enable Timer on a rule and link this preset.
  4. For subathons: enable Live Timer (or Automations -> Add Subathon) and pick this preset.

Options

  • Preset / Name: display name used with chat commands (!endtimer, !addtime, and so on).
  • Text style: font, weight, alignment, color, optional text shadow.
  • Live Clock: optional max remaining; accept adds while paused (see below).
  • Transform / crop / visibility / hotkey: shared stage controls.
  • On the delay Timer action, choose None (background only) for a wait with no overlay digits.

Live Clock

Live Clock is the extendable countdown for subathons. Automations add or start time via Live Timer; you can also control the clock from Overlay Layout (Start / Pause / Resume / End).

  • Accept adds while paused: when on (default), !addtime / RemoveTime still apply while paused.
  • Max remaining: optional cap so the clock cannot grow past a limit.
  • Live Timer Ended: automations can fire when the clock hits natural zero. Manual !endtimer abort does not fire that trigger.

Delay Timer behavior

  • Multiple rules can share one preset; they queue so only one delay countdown runs at a time.
  • Counter Action and Push Community Goal still apply immediately while the delay runs.
  • Sound, chat, TTS, wheel, giveaway, and alerts wait until the countdown ends.
  • !endtimer on a delay countdown skips deferred actions; it does not run them early.

Chat commands

  • Delay or Live Clock: !endtimer {name} (Built-in Commands; Live Clock abort does not fire Live Timer Ended).
  • Live Clock: !pausetimer, !resumetimer, !addtime, !removetime under Chat Bot - Live Timer Commands.

Full list: Chat commands.

Use cases

  • Subathon - Live Clock + Live Timer (or Add Subathon). Mods extend with !addtime.
  • Heist window mirror - Chat Games Open phase starts a delay Timer so overlay shows time left alongside Countdown Warnings in chat.
  • Background delay - Timer action with None (background only) when you need pacing without on-screen digits.
