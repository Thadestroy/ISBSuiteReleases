Timer Widget

Show a live countdown on your overlay when an automation or chat game uses the Timer action. Link the same named preset on the widget and on the action.

At a glance

  • Widget: Timer Widget.
  • Link the same named preset on the Timer action.
  • Style font, weight, color, alignment, and shadow like Alerts text.
  • Mods: !endtimer {Timer Widget name} ends early and skips deferred actions.

How it works

Timer Widget displays the active countdown for a named preset. Automations, Chat Bot, shop, and Chat Games enable the Timer action, set a duration, and link that same preset. When the rule fires, the widget counts down; deferred actions on that rule wait until zero (Counter Action and Push Community Goal still apply immediately).

Setup

  1. In Overlay Layout, add a Timer Widget and create or select a named preset.
  2. Style font, weight, color, alignment, and drop shadow (same text style controls as Alerts). Text size still scales with the widget box height.
  3. In an automation or chat game, enable Timer, set the duration, and link the same preset.
  4. When the rule fires, the widget counts down; deferred actions wait until zero.

Options

  • Preset: named timer this widget displays (must match the Timer action).
  • Name: display / command name used with !endtimer.
  • Text style: font, weight, alignment, color, optional text shadow.
  • Transform / crop / visibility / hotkey: shared stage controls.
  • On the Timer action, choose None (background only) for a delay with no overlay display.

Behavior

  • Multiple rules can share one preset; they queue so only one countdown runs at a time.
  • Counter Action and Push Community Goal still apply immediately while the timer runs.
  • Sound, chat, TTS, wheel, giveaway, and alerts wait until the countdown ends (see Timer action).

!endtimer

  • Mods end the active countdown with !endtimer {Timer Widget name}.
  • Customize the command name, permission, and optional Response under Chat Bot - Built-in Commands.
  • Ending skips deferred actions; it does not run them early. Waiting items in that preset's queue stay queued.
  • An unknown name gets a built-in chat reply. If you set a Response, it is sent whenever the command is used.

Use cases

  • Subathon clock - Long Timer on a large widget; mods use !endtimer only for emergencies.
  • Heist window mirror - Chat Games Open phase starts a Timer so overlay shows time left alongside Countdown Warnings in chat.
  • Background delay - Timer action with None (background only) when you need pacing without on-screen digits.
