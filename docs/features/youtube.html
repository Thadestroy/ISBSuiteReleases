YouTube

Beta. Request access to the YouTube API on Discord first, then Sign in with Google. YouTube-only editors, Send Message dest, and Stream Manager YouTube filters stay hidden until you connect (same idea as OBS Studio / Streamlabs Desktop). After connect, Chat Bot, alerts, Viewer Points, Community Goals, and Stream Manager Chat work on YouTube live chat the same way they work on Twitch, with a few YouTube-only rules. A rule that already targets YouTube keeps its editor if you Disconnect.

At a glance

  • YouTube is beta. Request API access on Discord, then connect under Integrations.
  • Read chat and Super Chat / member events from live chat. Send replies with the official YouTube send API.
  • Two-way !link joins a YouTube channel and a Twitch login into one ISB account.
  • YouTube lurkers never earn Watch Time. Only people who recently chatted count.
  • When the daily YouTube send budget is empty, reads and alerts keep working. Only pasting into YouTube chat stops until midnight Pacific.
  • Only-when-live features treat you as live if Twitch or YouTube is live. You go offline only when both are down.

Connect

  1. Request access to the YouTube API on Discord.
  2. Open Integrations.
  3. On the YouTube card, Sign in with Google as the channel that owns the live stream.

There is no YouTube bot account. Tokens stay on this PC.

Timed messages, walk-ons, Watch Time, and Stream Went Live use a combined live flag. A YouTube-only stream counts as live. A Twitch blip does not end the session while YouTube is still live. After both are offline, the next go-live is a new session so a Twitch-only day and a YouTube-only day do not share walk-on slots.

Link Twitch and YouTube

Linking joins a Twitch login and a YouTube @handle into one ISB account. After that, these are shared (one ticket, not two):

  • Watch time
  • Viewer Points
  • Walk-ons and once-per-stream limits
  • Community goal !contribute
  • Saved Lists
  • !sr queue caps
  • Giveaway, heist, and wheel joins

A link after both sides already have counters keeps the larger value on each counter (not a sum). Stats import can add YouTube @handle / UC... rows onto the same counter as Twitch. Viewers cannot unlink themselves. Unlink is on the Stats viewer row; counters stay on the surviving account.

How to link

  1. On Twitch, type !link @handle. On YouTube, type !link twitchlogin.
  2. From the other chat, that person confirms within about 10 minutes with !linkaccept name (or !link name). The name is the Twitch login or YouTube @handle that started it. YouTube uses the @handle, not the display name.
  3. A bare !link or !linkaccept explains the command. It does not finish a pending link, so a joke claim cannot be accepted by accident.

An account that is already linked cannot start another pair. A handle already linked to someone else cannot be claimed. The command is on by default under Chat Bot, Built-in Commands. Its Response is what bare !link says in chat. Rename, permission, and cooldown are on that card.

Permissions

Command replies stay on the platform they were typed. Timed messages, lobby opens, and the go-live line post to chats that are live in the current ISB session (Twitch-only stays off YouTube; YouTube-only stays off Twitch).

  • Subscribe on YouTube is the Follow rung (chat does not badge free Subscribe).
  • Member is the Sub rung.
  • No VIP. VIP+ is the same as Mods+.
  • Follows+ passes for owner, mod, member, or a linked Twitch follower.
  • Subs+ is owner, mod, or YouTube Member only. A linked Twitch sub does not pass.
  • Specific user lists accept YouTube @handle as well as Twitch login.

Watch Time and lurkers

Twitch Get Chatters wins. If a linked account is already in that list, YouTube is not counted again that tick. YouTube viewers who are not on Twitch earn only if they chatted inside the recently-chatted window (Watch Time setting; default 10 minutes). YouTube lurkers never appear. A YouTube-only day still accrues that window without Helix.

Alerts, points, and goals

YouTube Super Chat, Super Sticker, New Member, Member Milestone, Membership Gifter, and Membership Gift Receiver are their own types. They do not reuse Bits or Subs. {amount} is the YouTube display string (for example $5.00), not bits. New Member is first-time only. Member Milestone fires when they share it in chat. The YouTube alert section stays hidden until Sign in with Google. Free still allows 1 dedicated rule per type.

The same events can award Viewer Points and add Community Goal progress. Send Message can target YouTube, Twitch, or both. Chat Bot replies still stay on the platform the command was typed. Viewer Points !givepoints @handle and admin give look up a YouTube handle (recent chat, linked account, or official handle lookup) and credit that channel; all includes YouTube recently-chatted viewers and counts a linked account once.

Stream Manager

One combined Chat tile. Each line has a Twitch or YouTube mark. Show can hide one platform. Chat events include a Super Chat & members chip so those banners stay when the include-set is customized. Activity has a YouTube chip (not Integrations). The status strip shows YouTube connect, send quota, and live chat. Timeout, ban, and deleted-message lines from YouTube paint as mod notices. When send quota is empty, a notice still lands on Activity. The Viewers tile lists Twitch Get Chatters and YouTube recently-chatted in two sections. {randomViewer} picks from that union (linked accounts count once).

Send quota

Official YouTube send uses a daily unit budget that resets at midnight Pacific Time. When it is empty, ISB Suite stops pasting into YouTube chat only. InnerTube read, alerts, automations, watch time, and all Twitch send keep working. !link still hears both sides; confirm copy also goes to Activity / Stream Manager. The status chip says YouTube send is blocked until the next Pacific midnight.

Not on YouTube

Follow alerts, raids, Hype Train, Ad Break, Channel Points, Bits, Power-Up, Predictions, clips, and Twitch title/category are Twitch-only. YouTube has no lurker list; the Viewers tile shows recently-chatted names instead of concurrent viewers.
