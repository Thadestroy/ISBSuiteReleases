Counters and Stats

Track numbers that persist across streams, with tiers, leaderboards in chat, and CSV import/export.

At a glance

  • Global counters: one shared value. Per-user counters: value per Twitch viewer.
  • On Stats, each per-user card header shows a Total (sum of all users).
  • Change from automations, entry actions, or viewer points via Counter Action.
  • Leaderboard token: {top5Counter:CounterName} (per-user only).
  • CSV import accepts comma or semicolon (auto-detected).
  • Free: 5 counters. Built-in system counters and counters referenced by other features are exempt. Full limits on Free and Pro.

Counter types

  • Global: single shared value (for example Deaths This Stream, Wheels Spun).
  • Per-user: separate value per Twitch viewer (for example Times Won, Giveaway Entries). On the Stats page, the card header Total is the sum of every user's value (search does not change it).

Counter Action

Change counters from automations, wheel entry actions, or viewer-points redemptions:

  • Change by: signed number, plus/minus another counter, or a random min-max range rolled each fire.
  • Set to: absolute value (0 resets).
  • {amount} is the resolved amount from the first counter action in a fire.

Examples:

  • Change by -[tax pot] on a viewer's balance, then Set the pot to 0.
  • Range amounts (for example -100 to 100) roll once each time the action fires.
  • Increment Wins by 1 when a wheel entry wins, then announce {count} and {counterTier}.

Counter tiers

  • Any counter can have a tier ladder (for example 0 Bronze, 10 Silver, 50 Gold).
  • Active tier updates as values change and shows on the Stats page.
  • {counterTier}: tier for the current action, or the tier just gained on Counter Tier Reached.
  • {counterTier:CounterName}: current tier label for a named counter (live lookup).
  • On Counter Tier Reached, {counterTier} is the label for this crossing - not the final tier if several thresholds were crossed at once.

Related triggers: Counter Tier Reached and Counter Value Changed on Automations and Custom Alerts.

Leaderboards in chat

Use {top5Counter:CounterName} in any template to list the top 5 viewers on a per-user counter. Format: 1. Alice 100, 2. Bob 80, 3. Charlie 60, .... Empty when no data. Global counters do not support this token.

Example: Top 5: {top5Counter:Wins}. See Message variables.

CSV import and export

  • Export counters for backup or editing in a spreadsheet.
  • Import accepts comma- or semicolon-separated files (delimiter auto-detected; useful for Excel EU exports).
  • The downloadable template stays comma-separated.

Watch time

Stats Watch Time powers watching presence polls used by Viewer Points earn rules. Keep Twitch connected with the moderator chatters scope.
