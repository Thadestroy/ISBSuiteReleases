Alerts

Design follow, sub, bits, raid, and custom alerts with appearance presets, then play them in the Alert Box on your overlay - including from Automations, Chat Bot, shop, and Chat Games via Run Alert.

At a glance

  • Free: 1 dedicated alert per built in type, 3 Custom Alerts. Full table on Free and Pro.
  • Needs an Alert Box widget on the active Overlay Layout.
  • When several rules match, the most specific alert fires (exact amount and dedicated rules beat catch-alls).
  • Run Alert from Automations, Chat Bot, shop, and games reuses a designed alert. Related: Run Alert action, Automations, Message variables.

Twitch alert types

Follow, New Subscription, Resubscription, Subscription Gifter, Subscription Gift Receiver, Bits / Cheer, Raid, Hype Train End, Hype Train Level Up, Goal Achieved, Ad Break, Shoutout Received, Stream Went Live, Channel Point Redemption.

New Subscription fires only for a first-time paid sub (chat/Activity Feed notice). Returners and gift recipients do not get a New Subscription alert. Subscription Gifter is gifter-linked (bulk count). Subscription Gift Receiver fires once per recipient with {user} = gifted viewer and {gifter} = gifter (gift bombs = one alert per recipient). Resubscription fires when the viewer shares their resub message in chat. A silent payment or badge change with no chat notice does not fire a New Subscription alert.

Each type supports custom image or GIF, alert text with variables, display duration, TTS, and minimum thresholds (for example raids with 10+ viewers). Overview rows have an enable/disable light (same as Automations / Chat Bot); turning a type off and back on restores only the rules that were on before.

Appearance

Appearance is configured per alert:

  • Layout, fonts (live preview), colors, highlight, drop shadow, text delay, and fade timings.
  • Save and load reusable style presets (copy on apply).
  • Motion: enter/exit animations (Fade, slides, Scale, Bounce) and text enter (Fade, Slide up, Typewriter).
  • Preset vs Manual image/text positioning with offset sliders (percent of the Alert Box).
  • Side by side Layout | Motion | Preview columns with inline Test Alert (motion, sound, and TTS).
  • Overflow content soft fits (uniform scale down) so image and text stay visible; preview matches the live overlay.

Custom Alerts

Create alerts for trigger types that are not covered by the built-in per-type sections, from the Custom Alerts section on the Alerts page:

TriggerDetails
Community Goal ReachedWhen a community goal hits its limit
Counter Tier ReachedCounter crosses into the next configured tier
Counter Value ChangedCounter goes up, down, or either way (once per change)
First Chat MessageWalk on / catch all on a viewer first message
Chat CommandYour own !command (aliases, Match anywhere, permission, cooldown, limits)
TimerInterval or countdown driven alert
Action Only (Run Alert)No event trigger; only plays when an Actions surface uses Run Alert

Custom alerts support the same overlay options as built in alerts (image/GIF, sound, alert text, TTS, and chat response).

Run Alert

On Automations, Chat Bot, Viewer Points shop items, Chat Games, and other Actions surfaces, enable Run Alert and pick any Alerts page alert (built-in types, Custom Alerts, or Action Only). When the parent rule fires, that alert plays with the parent event context ({user}, amounts, and so on). The chosen alert must be enabled; its own cooldown and limits still apply. The Run Alert target list uses the same searchable dropdown as Randomized Action sets and Run Chat Bot or Automation.

Queued alerts play one at a time in the Home Alert Queue.

Legacy style note

Older alerts without a saved style keep the previous default look. Opening Appearance and saving (or applying a style preset) stores the new layout, motion, and typography for that alert going forward.
