Predictions

The Predictions tile creates a Channel Points Prediction from the desk and manages the live one. Create opens a popup for title, 2-10 outcomes, and the window. While a Prediction is ACTIVE or LOCKED, the tile shows the title, time left, and bet counts, with Lock, Cancel, and Pick winner. A Queued count (like the Queues tile) lists drafts that start after the live one ends - click it to review or remove them. There is no queue cap.

At a glance

  • Desk tile, visible by default under Stream info.
  • Title max 45 characters. Outcomes 2-10 (default Yes / No), 25 characters each. Window 30 seconds to 30 minutes (default 2 min). Enter sec or min.
  • Requires Affiliate or Partner and channel:manage:predictions. Re-authenticate Twitch once if you connected before this feature.
  • Only one Prediction can be ACTIVE or LOCKED. Create is hidden while one is live. Queue next saves drafts on this PC with no cap; the next starts after resolve or cancel, including when that happens on Twitch. Click the Queued count to list and remove them.
  • Manual create, lock, resolve, and cancel record Activity. Automations can also create via the Create Prediction action. If a Prediction is already live, that action queues the draft here instead of dropping it.
  • No auto chat announce. Add a Send Message action on a rule if you want to post the title.

Create

  1. Connect Twitch on Integrations. Grant Predictions management if prompted.
  2. Open Stream Manager. Click Create on the Predictions tile.
  3. Enter a title, at least two outcomes, and a window (seconds or minutes). Create sends the Prediction to Twitch.

The tile then shows the live Prediction. Activity shows the created title.

Manage

While a Prediction is running, the tile shows the title, remaining time, and how many people picked each outcome (or a count when there are more than three). Lock stops new bets early. Cancel refunds everyone (the tile asks first). Pick winner opens a popup with live totals; choosing an outcome pays those viewers.

After the window ends, Twitch locks the Prediction. You still have to pick a winner or cancel before you can create another. The tile also picks up a Prediction started on Twitch or by an automation (within about 15 seconds).

Queue

While a Prediction is live, Create stays hidden. Queue next opens the same popup and saves the draft on this PC with no cap. The Create Prediction action also queues here when Twitch already has one ACTIVE. The tile shows a Queued count (and the next title) like the Queues tile; click it for the full list and Remove. When the live one is resolved or canceled - here or on Twitch - ISB Suite starts the next queued Prediction even if Stream Manager is closed.

Limits

  • Twitch allows one ACTIVE or LOCKED Prediction per channel. You cannot edit the title, outcomes, or window after create.
  • If you do not resolve or cancel within 24 hours, Twitch refunds everyone.
  • Related: Create Prediction action for rules. Activity shows manual create, lock, resolve, and cancel.
