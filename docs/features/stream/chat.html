Chat

Chat is ISB's own transcript on the desk: emotes, a viewers list, and Bits or Gifted leaderboards. It is not a Twitch popout.

At a glance

  • Desk tile. People currently in chat (live or offline) are not the Stream CCV count.
  • Viewers from the Chat title-bar icon or the Viewers tile (hidden by default).
  • Chat settings: Bits period, timestamps, Slow mode, and Mod actions (saved on this PC).
On this page

  2. Bits and Gifted

Transcript

Messages paint in the Chat tile with Twitch emotes (and BTTV / 7TV / FFZ when those catalogs load). Channel Point redeems with text merge onto the chat line. Empty input shows as a redeem notice.

Bits and Gifted

Chevrons on the Chat leaderboard switch Bits and Gifted subs. Gifted shows who currently gifted a still-active sub on the channel. Twitch has no API for chat's all-time / month / week Top Gifters, so those lists will not match. Chat settings period is Bits only (All-time, This month, or This week).

Settings

The gear at the bottom of Chat picks timestamps, a Slow mode switch for the room, and Mod actions (ban / timeout / warn / delete on messages plus those lines in chat). Reconnect Twitch once if a button says it needs newer permissions.
