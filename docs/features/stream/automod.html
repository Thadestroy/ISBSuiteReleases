AutoMod

The AutoMod tab deletes Twitch chat messages that match a keyword or contain a link that is not on your allow list. This is ISB deleting the message after it hits chat. It is not Twitch's hold-for-review AutoMod.

At a glance

  • Stream Manager tab, not a desk tile and not a Chat Bot page.
  • Off until you turn it on. Keywords and links can each be turned off.
  • Keywords match anywhere in the message and ignore letter case.
  • Links stay when the host is allowed, or when the path contains what you typed (clips.twitch.tv, or twitch.tv/clip). A bare twitch.tv would allow every Twitch link.
  • Skip for is a role. That role and everyone above it can post. The broadcaster always can. New rules skip for Moderators+.
  • YouTube chat is not filtered.

How to use it

  1. Connect Twitch on Integrations. Chat delete uses the same permission as the delete button on a message. Re-sign in if deletes fail.
  2. Open Stream Manager, AutoMod.
  3. Add keywords, and keep or edit the clip allow list.
  4. Turn Delete matching messages on. A matching message is removed and does not run chat commands.

Links

A new install allows Twitch clips: clips.twitch.tv (any clip) and twitch.tv/clip (a channel clip URL such as twitch.tv/yourchannel/clip/...). Remove those rows if you do not want them. Clearing the list and saving keeps it empty.

VIPs, mods, and the other roles in Skip for can post links or keywords without a delete. Pick the role separately for keywords and for links.

Limits

  • Delete only. Timeout, ban, and a chat reply are not part of this tab.
  • Up to 200 keywords and 50 allow-list rows.
  • Your linked bot is not filtered, so its replies are not deleted.
  • If Twitch does not give ISB a message id, the message is not deleted, and it still does not run commands.
