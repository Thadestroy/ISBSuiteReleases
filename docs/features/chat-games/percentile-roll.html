Percentile roll

Roll a custom min-max (for example 1-100), map bands to Actions, and optionally use alternate outcome tables per viewer login.

At a glance

  • Preset: Percentile roll (dice / range outcomes).
  • No stakes and no timed join window by default.
  • Each band uses the full Actions editor.
  • Tokens: {roll}, {outcome}.
  • Outcome profiles: Default table or a copy for a specific Twitch login.

How it works

On fire, ISB Suite rolls within your configured min-max, finds the matching outcome band on the active profile, and runs that band's Actions. Nested chains keep {roll} and {outcome} available. Full token table: Message variables - Chat Games.

This preset is for table-driven loot / crit systems - not for pooling stakes. Pair with channel points or a chat command as the start trigger.

Setup

  1. Create a Percentile roll from Chat Games presets.
  2. Pick start triggers (command, channel points, and so on).
  3. Set the die min-max (for example 1-100).
  4. Add bands that cover the full range without gaps you care about (for example 1-89 Normal, 90-100 Crit).
  5. On each band, enable Actions (chat, sound, alert, counters, Randomized Action, and so on).
  6. Set cooldowns and limits under Start Triggers / Advanced Settings.

Options and bands

  • Dice roll min / max: inclusive range for the roll.
  • Outcome band: name, min, max, and its own Actions list.
  • Band names become {outcome} in templates (for example Normal, Crit).
  • Cover the whole die range; overlapping or missing edges produce surprising matches - keep bands tidy.
  • Stakes / timed session are usually off; add Counter Action inside a band if a roll should spend or grant points.

Outcome profiles

Use the Outcome profile dropdown for the Default table, or duplicate it for a specific Twitch login so that viewer gets a different band table. Runtime picks the username profile when present, otherwise Default.

  • Good for VIP / staff softer fail tables, or a harsher "hard mode" login.
  • Keep band names consistent across profiles if you reuse the same chat templates.

Use cases

  • d100 loot - Channel points -> bands for common / rare / jackpot with different Run Alert designs.
  • VIP table - Alternate profile for a VIP login with softer fail bands.
  • Crit only hype - Crit band runs Randomized Action + sound; Normal band is chat-only.
  • Counter tax - Each band includes Counter Action Change by -cost so rolls spend currency without Chat Game stakes.
