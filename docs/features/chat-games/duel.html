Duel

Instant per-user gamble: each trigger bets points immediately with separate Win and Lose action phases.

At a glance

  • Preset: Duel.
  • No timed join window - fires per trigger.
  • Variable stake, win chance, and payout multiplier.
  • Separate Win and Lose action phases per entrant.
  • Related: Actions, variables.

How it works

A Duel does not collect a room of entrants over time. Each start trigger (command, channel points, and so on) takes the stake and rolls win/lose for that viewer immediately, then runs the matching phase Actions. There is no open/summary session messaging unless you add your own Send Message Actions on Win/Lose.

Use Duel for spammy, per-viewer gambles. Use Heist/Lottery when you want a shared timed window.

Setup

  1. Create a Duel from Chat Games presets.
  2. Set stake counter, variable stake mode, win chance, and payout multiplier.
  3. Add start trigger(s) - often a chat command that accepts an amount, or a fixed channel points redeem.
  4. Enable Execute Actions on Win / Lose and configure those phase Actions (chat, sound, counters, Run Alert).
  5. Set Advanced Settings (permission, cooldown, once per viewer per stream) so duels cannot drain balances instantly.

Options

  • Timed session: off - no join window.
  • Stake mode: Variable (command amount) or Fixed (redeem with a set cost).
  • Win chance % and Payout multiplier: classic 50% / 2x duel math is a common starting point.
  • Execute Actions on Win / Lose: turn on the phase lists you care about.
  • Open / summary chat templates are usually left off; put copy in the Win/Lose Actions instead.

Phases

  • Win - per successful roll: hype sound, Run Alert, Counter Action on Wins, Send Message with {user} / stake tokens.
  • Lose - per failed roll: soft chat, fail sting, or a consolation counter bump.

There is no When Session Ends for Duel. Nested Actions still share the game context for Chat Games variables where applicable.

Use cases

  • !duel 50 - Command with stake from input; Win phase Change by +1 on Wins + hype sound.
  • Points redeem duel - Channel points item opens a fixed-stake duel (no amount typing).
  • Cooldown-gated spam - Short cooldown + once per viewer per stream so the counter economy stays healthy.
  • Shared hype pack - Win phase calls Run Chat Bot or Automation into a reusable celebration rule.

Related: Instant action (no stakes), Heist (timed room).
