Lottery

Fixed entry fee lottery: viewers buy in during a timed window; when it closes, one winner takes the whole pool.

At a glance

  • Preset: Lottery.
  • Fixed stake; single winner; pool payout.
  • Timed join window with open / join / end messages.
  • Optional min entrants before a real draw.
  • Variables: Chat Games tokens.
On this page
  1. How it works
  2. Setup

How it works

Each joiner pays the same fixed fee into a shared pool. When the duration ends, one winner is drawn (single-winner resolution) and receives the pool. Empty sessions can use If No One Joins. Unlike Heist, there is no per-entrant win chance - the draw picks one winner from everyone who entered.

Setup

  1. Create a Lottery from Chat Games presets.
  2. Add a start trigger that opens the session.
  3. Set fixed entry fee, stake counter, duration, join command, and optional min entrants.
  4. Write opened / join-confirmed / winner summary templates; add Countdown Warnings if useful.
  5. Wire phase Actions for Open, Join, When Session Ends, and If No One Joins as needed.
  6. Set start Chat Command Advanced Settings (permission, aliases) and the shared Start Triggers Cooldown & Limits card.

Options

  • Stake mode: Fixed - every entrant pays Fixed stake amount.
  • Stake counter: counter debited on join and used for payouts.
  • Min entrants: optional floor (for example 2) before the lottery resolves as a real draw.
  • Resolution scope: Single winner drawn from the pool.
  • Payout mode: Split / pay total pool to the winner (classic lottery pot).
  • Duration: join window; join-confirmed messages can show live {totalPool}.
  • Win chance: not used for single-winner pool draws (leave at 0 / ignore).

Phases

  • Open - announce the lottery and show the join command.
  • Join - optional Actions when someone buys in (pool grows).
  • When Session Ends - announce {winnersList}, {totalPaidOut}, {winnerCount}.
  • If No One Joins - cancel / soft message when the window closes empty.

Tokens for messages and Actions: Message variables - Chat Games.

Use cases

  • Sub raffle - Subs+ join permission, 5 minute window, winner chat with {winnersList} and {totalPaidOut}.
  • Channel points lottery - Start trigger on a redeem that opens the lottery session; fixed fee from Stream Coins.
  • Pot ticker - Join-confirmed message with {user} and {totalPool} so chat sees the pot grow.
  • Wheel for the winner - When Session Ends runs Start Wheel Session after announcing the winner.
