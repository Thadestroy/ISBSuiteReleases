Chat Games

Mass entry chat games where viewers join from chat, stake a counter value, and get independent or shared outcomes. Each preset has its own setup page with options, phases, and example recipes.

At a glance

  • Free: no separate Chat Games cap (stake counters and other features still follow their Free limits). Full table on Free and Pro.
  • Presets: Heist, Lottery, Duel, Percentile roll, Blank sandbox, Instant action.
  • Join and start commands support aliases and Match anywhere. Phases use the same Actions editor as Automations.
  • Variables: Message variables - Chat Games.

Shared setup

Managed in the Chat Games tab. Each game is its own rule with the same trigger and action building blocks as Automations. Overview pages support name search and custom groups.

  • Start triggers: chat command, channel points, and the same trigger types as Automations. Use these to open a timed session or fire an instant game.
  • Join command with optional aliases and Match anywhere (Advanced Settings) on timed games.
  • Chat messages for open, join confirmed, summary, and cancel (enable the ones you need).
  • Countdown Warnings: reminder message plus remaining-time offsets; use {timeLeft}. Offsets at or beyond session length are skipped.
  • Permission, cooldown, and per-stream limits (including once per viewer per stream) sit with start/join Advanced Settings on every chat command.

Phases

Chain sounds, alerts, wheels, or other actions to these phases (not every preset uses every phase):

  • Open - session starts and join becomes available.
  • Join - a viewer successfully enters (stake taken when stakes are on).
  • Resolve / When Session Ends - timed window closes and outcomes are calculated.
  • Win and Lose - per-entrant outcome phases.
  • No Winners - people joined but nobody won (for example Heist). Separate from When Session Ends.
  • If No One Joins - path for empty sessions.

Phase Actions use the shared Actions editor (sound, chat, Run Alert, Timer, Randomized Action, and so on).

Stakes and payout

When a preset uses stakes, pick a stake counter (often your Viewer Points currency counter). Common modes:

  • Variable stake: viewer supplies an amount (for example !heist 50).
  • Fixed stake: every entrant pays the same fee into the pool.
  • Win chance and payout multiplier: used when each entrant rolls independently (Heist / Duel).
  • Resolution scope: each entrant vs a single winner drawn from the pool (Lottery).
  • Payout mode: multiply the stake, or pay out / split the total pool.
  • Min entrants: optional floor before a timed game will resolve as a real draw.
