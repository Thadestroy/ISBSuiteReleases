Wheel

Animated prize wheels with chat join, mod control, Quick Launch presets, custom colors, and per entry win actions.

At a glance

  • Free: 3 wheel presets. Full table on Free and Pro.
  • Viewers join with !join when a session allows chat join.
  • Mods and broadcaster: !startwheelspin, !spinwheel, !endwheelspin, !resetwheelspin.

Overview

Create and customize wheels from the Wheel Editor tab. Save multiple presets (for example a prize wheel, a game picker, or a category picker) and load them from Quick Launch or from an automation.

  • Smooth spin animations and custom color palettes (per wheel or per entry).
  • Viewer Twitch name colors on slices when they !join.
  • Configurable winner chat messages with message variables.
  • Remove on win mode and allow duplicates mode.
  • Quick Launch presets: one click loads and optionally auto spins a saved wheel.
  • Transparent background for window capture in OBS or similar tools. See Download - Capture.

Wheel Editor settings

  • Wheel Name: shown in Quick Launch and in {wheel} where that variable is available.
  • Allow !join from Chat: let viewers add themselves during an open session.
  • Remove Winners After Spin: auto-removes the winner slice so it cannot win twice on later manual spins.
  • Allow Duplicates: permit the same name on the wheel more than once.
  • Announce Winner in Chat: send the winner message to Twitch chat automatically.
  • Custom Winner Message: override the default The winner is: {winner}! template. Supports variables such as {winner}, {user}, and counter tokens.

Managing entries

  • Add entries one at a time with + Add Entry.
  • Bulk import from text with Bulk Import (one entry per line).
  • Edit text, color, and per entry actions for each entry.
  • Duplicate entries to quickly clone text, colors, and actions.

Color customization

  • Default palette: automatic rainbow distribution across all slices.
  • Custom palette: click the color squares in the editor to set hex values for the wheel.
  • Per entry color override: set a specific color for individual entries.
  • Twitch user colors: applied automatically when viewers !join.

Chat and Twitch

Connect Twitch on Integrations so chat commands and EventSub work.

  • Viewers: !join during an open session (when Allow !join is on).
  • Mods and broadcaster: !startwheelspin (empty wheel, enables join), !endwheelspin (stop join), !spinwheel, !resetwheelspin (clear and end session).
  • Crash recovery and reconnect handling are built in.
  • Optional dedicated bot account on Integrations: chat replies (wheel outcomes, automations, alerts, chat bot) send as the bot while the broadcaster account stays for triggers. Available on Free. Mod the bot in your channel for higher chat rate limits.

Per entry actions

Each wheel entry can run its own actions when it wins:

  • Play a sound file with volume control.
  • Send a custom chat message (supports variables).
  • Run a Counter Action (Change by or Set to; number, plus or minus another counter, or a random range). See Counters and Stats.
  • Trigger another automation (including cascading into a second wheel).
  • Override the wheel winner announcement for that entry.
  • Set a custom color for that entry slice.

When a wheel entry win triggers an automation, {winner} resolves to the winning entry name. Pending loads and spins appear on the Home Wheel Queue.

Cascading wheels

  1. Create multiple wheel presets (for example Category Picker and Game Picker).
  2. On an entry in Category Picker, add a trigger automation action.
  3. That automation uses Load and Spin Wheel to load the Game Picker (optionally auto spin).
