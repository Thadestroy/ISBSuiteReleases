Actions

The same Actions editor appears on Automations, Chat Bot, Viewer Points shop items, Chat Games, and related surfaces. Pick what should happen when a rule fires; each action has its own options and Test controls where it makes sense.

At a glance

  • One shared Actions control - not a separate app feature with its own Free limit.
  • Used from Automations, Chat Bot, shop items, and Chat Games.
  • Many actions support message variables ({user}, {amount}, and so on).
  • Open a card below for how each action works, options, and pitfalls.

Where Actions appear

Whenever you configure what happens after a trigger or redeem, you get this Actions list. Labels match the checkboxes in the app.

  • Automations and Chat Bot: full action set on each rule.
  • Viewer Points shop: redeem runs the item Actions.
  • Chat Games: phase Actions (open, join, win, and so on).
  • Wheel entries: a smaller per-entry set (sound, chat, counter, run automation). See Wheel - Per entry actions.

How Actions run together

  • You can enable several actions on one rule. They share the same trigger context ({user}, amounts, and so on).
  • Timer is special: Counter Action and Push Community Goal still apply immediately so {count} stays correct; sound, chat, TTS, wheel, giveaway, and alerts wait until the countdown ends.
  • Randomized Action replaces the flat action list with named Action Sets - each fire picks one set.
  • Free limits apply to the parent feature (automations, chat bot commands, shop items), not per action type.

Setup tips

  • Use Test / Test TTS on sound and speech actions before going live.
  • Prefer one shared "hype pack" automation and call it with Run Chat Bot or Automation from several commands.
  • For variety from one redeem, use Randomized Action instead of many near-duplicate rules.
