Start Giveaway Session

Open a timed giveaway that chatters join with a command. When time is up, a winner is chosen with optional chat, sound, TTS, and counter increment.

At a glance

  • UI label: Start Giveaway Session.
  • Starts an empty joinable session; viewers type the join command (default !giveaway).
  • Duration auto-resolves the winner; Advanced settings add countdown reminders.
  • Related: Queues and Giveaways.

How it works

On fire, ISB Suite opens a joinable giveaway session. Viewers enter with the configured command (permission gated). When the duration elapses, a winner is picked - optional winner chat, sound, TTS, and a per-user counter increment. Duplicate joins can get an already-joined reply with its own cooldown. Home queues/handoff details: Queues and Giveaways.

Setup

  1. Enable Start Giveaway Session.
  2. Set join command, join permission, duration, and optional winner counter.
  3. Tune opened / already-joined / winner messages, then Advanced countdown offsets if you want reminders.

Options

  • Join command / Join permission: who can enter and with which command.
  • Duration: seconds, minutes, or hours until auto-resolve.
  • Counter + Increment amount: optional per-user counter bump for the winner.
  • Send opened message / already joined message / winner chat: templates with variables such as {user}, {timeLeft}, {duration}.
  • Winner sound / winner TTS: optional celebration when the winner is chosen.

Advanced settings

Under Advanced: editable reminder message plus custom remaining-time offsets (same style as chat-game and Ad Break pre-warnings). Offsets at or beyond the giveaway length are skipped. Use {timeLeft} and {duration} in reminder text.

Use cases

  • Mod-run prize drop - Mod command -> 5 minute giveaway, !giveaway, opened message names the prize, winner chat + TTS, +1 on per-user Wins.
  • Sub-only redeem - Channel points "Start giveaway" -> same action with Subs+ join permission so only subs can enter.
  • Reminder-heavy hype - Longer duration with Advanced offsets at 5m / 1m / 30s so chat gets nudged before close.
