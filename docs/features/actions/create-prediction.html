Create Prediction

Start a Twitch Prediction when a rule fires (bits, redeem, command, and so on). Requires Affiliate or Partner. Announce it on the same fire with {predictionTitle} or {predictionId}.

At a glance

  • UI label: Create Prediction.
  • Helix Create Prediction (channel:manage:predictions). Re-authenticate Twitch once if you connected before this feature.
  • Title max 45 characters after variables resolve. 2-10 outcomes (default Yes / No). Window 30-1800 seconds (default 120).
  • Runs before Send Message / TTS / Discord / alerts so {predictionTitle} / {predictionId} resolve on the same fire.

How it works

When the rule fires, ISB Suite asks Twitch to create a Channel Points Prediction. Only one Prediction can be ACTIVE on a channel. If one is already live, the draft joins the Stream Manager Predictions queue and starts after the live one ends. A missing permission or a non-Affiliate account still fails quietly. The rest of the rule still runs. {predictionTitle} / {predictionId} stay literal unless create succeeded on that fire.

Setup

  1. Connect Twitch under Integrations (grant Predictions permission when prompted).
  2. Enable Create Prediction on the Actions card.
  3. Set the title, 2-10 outcomes, and the betting window.
  4. Add Send Message (or Discord / TTS) with {predictionTitle} if you want chat to announce the Prediction.

Tokens

{predictionTitle} is the created question. {predictionId} is Twitch's Prediction id. Both are unset unless Create Prediction succeeded on that fire. See Message variables.

Examples

  • Channel points "Call it" -> Create Prediction + Send Message {user} started: {predictionTitle}.
  • Raid -> Create Prediction (Yes / No, 120s) + Discord webhook with the same title.
