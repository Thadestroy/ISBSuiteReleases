Live Timer

Drive a Live Clock on a Timer Widget - the subathon-style countdown you can start, pause, and extend. Separate from the delay-queue Timer action.

At a glance

  • UI label: Live Timer.
  • Requires a Timer Widget preset set to Live Clock (not a delay Timer).
  • Starts at + a per-trigger table (Add / Start / Ignore). Applies immediately, like counters.

How it works

Enable Live Timer, pick a Timer Widget preset, set Starts at, and fill the per-trigger time table. When the rule fires, the Live Clock updates right away (Add time, Start from Starts at, or Ignore). Nested Run Chat Bot or Automation gets its own row in that table.

You can also use a delay Timer on the same rule; Live Timer still applies immediately while other actions wait for the delay.

Setup

  1. Create a Timer Widget preset in Overlay Layout, set it to Live Clock, and place the widget on a layout.
  2. On the automation, enable Live Timer, pick that preset, set Starts at, and choose Add / Start / Ignore per trigger.
  3. (Optional) Add a Live Timer Ended trigger on another rule for when the clock hits natural zero.

Live Timer vs Timer

  • Live Timer: extendable Live Clock for subathons. Overlay Layout Start / Pause / Resume / End; optional max remaining and accept-adds-while-paused.
  • Timer: delay-queue wait before deferred actions on that rule. Not for adding time from bits/subs.

Do not use a long delay Timer to fake a subathon. Use Live Timer + Live Clock.

Chat and Live Timer Ended

Mods use !pausetimer, !resumetimer, !addtime, !removetime, and !endtimer with the Timer Widget name. Those built-ins live under Chat Bot - Live Timer Commands (!endtimer is also under Built-in Commands for delay timers). Full list: Chat commands.

Live Timer Ended fires when the clock hits natural zero (optional Timer Widget filter). Manual !endtimer abort does not fire it.

Examples

  • Bits -> Live Timer Add 30s; Gift Subs -> Add 2m; chat command -> Start from Starts at.
  • Extension / Blerp bits -> Chat Message Match (bot username + used <amount> bits) with Count each + Live Timer Add (same pattern as Bits). Do not also add a Bits cheer trigger for the same Blerp line.
  • Live Timer Ended -> Send Message + Play Sound when the subathon clock empties.
