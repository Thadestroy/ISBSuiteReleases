Timer

Wait after the trigger, then fire the deferred actions together. Optionally show a Timer Widget on the overlay while you wait.

At a glance

  • UI label: Timer.
  • Counters and community goals update immediately; sound, chat, TTS, wheel, giveaway, and alerts wait.
  • Link a Timer Widget preset, or None (background only).
  • Mods: !endtimer {Timer Widget name} ends early and skips deferred actions.

How it works

Enable Timer and set how long to wait after the trigger (seconds, minutes, or hours). When the countdown finishes, the deferred actions on that same rule fire together. Linked Timer Widgets show the live countdown on stream; multiple rules that share one preset queue so only one countdown runs at a time.

Setup

  1. (Optional) Create a Timer Widget preset in Overlay Layout and place the widget on a layout.
  2. Enable Timer, set the wait, pick the preset or None (background only).
  3. Enable the actions that should run after the wait (Send Message, Play Sound, and so on) on the same rule.

What waits vs what runs now

From the editor copy in the app:

  • Immediate: Counter Action and Push Community Goal (so {count} / goal progress stay correct in messages that fire later).
  • Deferred until countdown ends: sound, wheel, giveaway, alert, chat, TTS, and related presentation actions.

!endtimer cancels the countdown and skips deferred actions - it does not run them early.

Overlay and !endtimer

Presets and widget placement: Overlay Layout - Timer Widget. Mods end an active named countdown with !endtimer {Timer Widget name}. Background-only timers have no on-screen widget but still delay actions the same way.

Examples

  • Channel points "Boss in 60s" -> Timer 60s on Main Timer, then Send Message + Play Sound.
  • Counter + Timer on one rule: increment Wins immediately, announce in chat when the timer ends.
