Randomized Action

Define several Action Sets on one rule. Each fire picks one set - uniform random, or no repeat until every set has played.

At a glance

  • UI label: Randomized Action (above the main Actions grid).
  • Each set is a full Actions payload (sound, chat, wheel, and so on).
  • Modes: uniform, or Don't repeat until all Action Sets have played.
  • Nested Randomized Action inside a set is stripped - keep randomness on the parent only.

How it works

When Randomized Action is enabled, the parent rule no longer runs one flat action list. Instead it picks one named Action Set each fire and runs that set's Actions. Sets are searchable in the editor. Use this for rotating hype lines, stingers, or mystery wheel loads from a single redeem or command.

Setup

  1. Enable Randomized Action at the top of Actions.
  2. Add Action Sets and name them (Prize Wheel, Hype Pack, Alert Burst).
  3. Inside each set, enable the Actions for that outcome (Send Message, Play Sound, Start Wheel Session, and so on).
  4. Choose uniform vs no-repeat-until-all.

To reuse an existing setup, use Import from Automation / Chat Bot above Randomized Action (copies flat actions or Action Sets). Extract on a set creates a standalone Automation for reuse.

Action Sets

Each set is a complete Actions editor. Switch sets in the picker to edit that outcome. One redeem can land on a wheel, a sound+TTS pack, or an alert - without duplicate rules.

Modes

  • Uniform (default): every set has the same chance every fire.
  • Don't repeat until all Action Sets have played: shuffle-bag style - every set plays once before any set repeats.

Use cases

  • Mystery prize redeem - Channel points -> three sets: Start Wheel Session on Prize Wheel, a sound+TTS hype pack, and Run Alert - with no-repeat so viewers cycle the pool.
  • Raid variety - Raid automation -> several Play Sound + Send Message sets so back-to-back raids do not feel identical.
  • Shop roulette - Viewer Points item -> sets that each Start Wheel Session on a different preset plus a unique chat line.
