Randomized Action

Define several Action Sets on one rule. Each fire picks one set - uniform random, or no repeat until every set has played.

At a glance

  • UI label: Randomized Action (above the main Actions grid).
  • Each set is a full Actions payload (sound, chat, wheel, and so on).
  • Modes: uniform, or Don't repeat until all Action Sets have played.
  • Import .txt, Edit lines, and Export .txt work with Send Message sets (one line = one set). Edit lines is a searchable list: edit or add a line in that window, Ctrl/Shift-click to select several, and double-click a line to close it and jump to that set's Actions.
  • Nested Randomized Action inside a set is stripped - keep randomness on the parent only.

How it works

When Randomized Action is enabled, the parent rule no longer runs one flat action list. Instead it picks one named Action Set each fire and runs that set's Actions. Sets are searchable in the picker. Use this for rotating hype lines, stingers, or mystery wheel loads from a single redeem or command.

Setup

  1. Enable Randomized Action at the top of Actions.
  2. Add Action Sets and name them (Prize Wheel, Hype Pack, Alert Burst), or use Import .txt / Edit lines to create one set per Send Message line.
  3. Inside each set, enable the Actions for that outcome (Send Message, Play Sound, Start Wheel Session, and so on). After a line import, open Edit lines, search, and double-click a line to jump to that set and add extras (sound, TTS, wheel) on that set only.
  4. Optional: check Copy other actions from the selected set so every imported line also gets that set's extras, then overwrites Send Message.
  5. Choose uniform vs no-repeat-until-all.

To reuse an existing setup, use Import from Automation / Chat Bot above Randomized Action. A randomized source copies its Action Sets; a flat Chat Bot or Automation becomes one Action Set so Send Message stays on the set (not the Chat Bot parent Response field). Play Sound files are copied onto this rule. Extract on a set creates a standalone Automation for reuse and copies that set's sounds onto the new rule.

Import .txt turns a list of chat lines into Action Sets (UTF-8, one non-empty line per set). The file is copied in - it is not watched on disk. Append keeps existing sets; Replace wipes them (you get an extra confirm if any set has actions besides Send Message). If you already have Action Sets, Edit lines opens a popup generated from those sets so you can search, edit or add a line in place, or edit-as-text. Ctrl+click and Shift+click select more than one line to delete. Double-click a line to close the popup and jump to that set's Actions. Export .txt writes Send Message templates for sets where Send Message is on, one per line. Hundreds of rotating lines still share the same Twitch chat rate limit.

Action Sets

Each set is a complete Actions editor. Switch sets in the picker to edit that outcome. One redeem can land on a wheel, a sound+TTS pack, or an alert - without duplicate rules.

Modes

  • Uniform (default): every set has the same chance every fire.
  • Don't repeat until all Action Sets have played: shuffle-bag style - every set plays once before any set repeats.

Use cases

  • Mystery prize redeem - Channel points -> three sets: Start Wheel Session on Prize Wheel, a sound+TTS hype pack, and Run Alert - with no-repeat so viewers cycle the pool.
  • Raid variety - Raid automation -> several Play Sound + Send Message sets so back-to-back raids do not feel identical.
  • Rotating chat lines - Import a .txt of hype lines, or open Edit lines from the sets you already have, then search and double-click a line to attach a sound or TTS.
  • Shop roulette - Viewer Points item -> sets that each Start Wheel Session on a different preset plus a unique chat line.
