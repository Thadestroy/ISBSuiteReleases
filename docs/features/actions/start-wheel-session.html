Start Wheel Session

Load a saved wheel preset when the rule fires. Optionally spin immediately, remove winners, or keep spinning until one entry remains.

At a glance

  • UI label: Start Wheel Session.
  • Loads a preset from Wheel Editor; auto-spin is optional.
  • Without auto-spin, the session opens so chat can !join if the preset allows it.
  • Related: Queues and Giveaways, Randomized Action.
On this page
  1. How it works

How it works

When the parent rule fires, ISB Suite loads the chosen wheel preset into the live session (same idea as Quick Launch). If Automatically spin immediately is off, the wheel is ready for joins or a later mod !spinwheel. If auto-spin is on, a spin starts after the configured delay without a separate spin command.

Winner chat, entry sounds, and per-entry actions still come from the wheel / entry settings. This action only starts (and optionally spins) the session.

Setup

  1. Save the wheel preset in Wheel Editor (entries, join settings, winner message).
  2. On the rule, enable Start Wheel Session and pick that preset.
  3. Decide load-only vs auto-spin, then optional remove-winner / last-survivor modes.

Options

  • Wheel Preset: which saved wheel to load.
  • Automatically spin immediately: spin after a short delay. If unchecked, the session starts but does not spin on its own (viewers can join when Allow !join is on).
  • Remove winner after spin (with auto-spin): drop the winning slice and keep spinning for elimination-style games.
  • Spin until one entry remains: keep removing winners until a last survivor is left.
  • Number of spins / Delay between spins: when removing winners without last-survivor mode, how many spins and the pause between them so viewers can see each result.

Examples

  • Channel points "Spin the Prize Wheel" -> Start Wheel Session on Prize Wheel with auto-spin after 3 seconds.
  • Mod command opens an empty joinable wheel (auto-spin off) so chat !join, then mods spin later.
  • Put different presets in Randomized Action sets for a "mystery wheel" redeem.
