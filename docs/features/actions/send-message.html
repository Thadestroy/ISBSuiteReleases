Send Message

Send a Twitch chat line when the rule fires. Templates support message variables from the parent event, with a live preview in the editor.

At a glance

  • UI label: Send Message.
  • Supports message variables such as {user} and {amount}.
  • Optional bot account on Integrations sends replies as the bot.
  • TTS and Discord can reuse this same template text.
  • /shoutout {user} or /so {user} fires Twitch's official shoutout (reconnect Twitch if you connected before this feature).

How it works

When the rule fires, the template is resolved with the current event context and sent to Twitch chat (as the broadcaster account, or as the dedicated bot account if you connected one on Integrations). Rate limits still apply - mod the bot in your channel if you send many replies. A template that starts with /shoutout or /so sends Twitch's official shoutout (Helix) instead of posting that slash command. Viewer text in {input} is posted as chat. /shoutout {user} on a raid uses the raider's user id. You must be live with at least one viewer; one shoutout every 2 minutes, same channel once per hour. Extra text after the name is still sent as chat. Re-authenticate Twitch if you connected before this feature (moderator:manage:shoutouts).

Setup

  1. Enable Send Message.
  2. Write the Message Template. Use the Variables helper to insert tokens.
  3. Check the green Preview line (sample viewer / amounts) before saving.

Variables and preview

Tokens resolve from the event that fired the parent rule (and from counters, goals, and other systems where those tokens are valid). Common ones: {user}, {amount} (shared cascade - raid viewers and resub months map here; there is no {viewers} / {months} token), {count}, {input}. Full catalog: Message variables.

Reuse by other actions

  • Text-to-Speech can speak this same Send Message text.
  • Discord Webhook can post this same text to Discord.
  • You do not have to duplicate the template unless you want different wording per destination.

Examples

  • Bits cheer -> Thanks {user} for {amount} bits! plus Push Community Goal with Use amount from trigger.
  • Raid -> Send Message /shoutout {user} for the official shoutout, or /shoutout {user} Welcome raiders! to shout out and still post a chat line.
