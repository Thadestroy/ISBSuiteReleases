Create Clip

Create a Twitch clip when a rule fires (bits, redeem, command, and so on). The channel must be live. Announce the clip on the same fire with {clipUrl} or {clipId}.

At a glance

  • UI label: Create Clip.
  • Helix Create Clip (clips:edit). Re-authenticate Twitch once if you connected before this feature.
  • Duration 5-60 seconds (default 30). Optional clip title uses the same message variables as Send Message (including trigger tokens such as {input}).
  • Runs before Send Message / TTS / Discord / alerts so {clipUrl} / {clipId} resolve on the same fire.

How it works

When the rule fires, ISB Suite asks Twitch to start a clip. Creation is asynchronous: the public clip URL can 404 for a few seconds. Offline channels fail quietly (the rest of the rule still runs) and leave {clipUrl} / {clipId} as literal tokens.

Setup

  1. Connect Twitch under Integrations (grant clip permission when prompted).
  2. Enable Create Clip on the Actions card.
  3. Set duration (5-60 seconds) and an optional title.
  4. Add Send Message (or Discord / TTS) with {clipUrl} if you want chat to announce the clip.

Tokens

{clipUrl} is https://clips.twitch.tv/{id}. {clipId} is the clip slug. Both are unset unless Create Clip succeeded on that fire. See Message variables.

Examples

  • Channel points "Clip that" -> Create Clip + Send Message {user} clipped: {clipUrl}.
  • Bits 1000 -> Create Clip (60s) + Discord webhook with the same {clipUrl}.
